## Overview:
Turning real-life situations into data-driven insights. This is my first real-time data analysis project, based on a trip to Wonderla with 8 friends, where we tracked and analyzed our shared expenses. The primary goals of the project are to practice advanced SQL skills and generate valuable insights from the dataset.

## Project Steps

### 1. Data Exploration
Before diving into SQL, it’s important to understand the dataset thoroughly. The dataset contains attributes such as:
- `Name`: The Person who are in our trip.
- `Expenses`: The one who expense.
- `Catregory`: The expenses belong to the Category.
- `Amount`: The amount spend on the category (e.g., Snacks, Wonderla Pass, etc...).
- `Date`: How many Days We were in  the trip.
- `Notes`: Breif note about the category expenses
- `Paid By`: The one who paid the expense.
- `Total Paid`: This is same as Paid By.

### 2. Data Integrated
 Here the data is stored in the Excel, so here directly connected with the Excel to MySQL by using JDBC.
- Create New Schema in MySQL.
- Right Click on the Schema then import data.
- It opens a Dialog Box.
- Select the Data Type based on the entity.
- Save it.

### 3. Querying the Data
After the data is inserted, various SQL queries can be written to explore and analyze the data. Queries are categorized into **easy**, **medium**, and **advanced** levels to help progressively develop SQL proficiency.

## Technology Stack
- **Database**: MySQL
- **SQL Queries**: DDL, DML, Aggregations, Joins, Subqueries, Window Functions
- **Tools**:MySQL, Excel
